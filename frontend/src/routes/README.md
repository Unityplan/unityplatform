# TanStack Router Routes

This directory contains file-based routes for the UnityPlan frontend application.

## Route Structure

- `__root.tsx` - Root layout component, wraps all routes
- `index.tsx` - Home page route (`/`)
- `login.tsx` - Login page route (`/login`)
- `register.tsx` - Registration page route (`/register`)
- `reset-password.tsx` - Password reset route (`/reset-password`)
- `dashboard.tsx` - Protected dashboard route (`/dashboard`)
- `profile.tsx` - Protected profile view route (`/profile`)
- `profile.edit.tsx` - Protected profile edit route (`/profile/edit`)

## Protected Routes

Routes that require authentication use the `<AuthGuard>` component:
- `/dashboard`
- `/profile`
- `/profile/edit`

## Auto-Generated Files

The `routeTree.gen.ts` file is automatically generated by the TanStack Router plugin.
**Do not edit this file manually.**

## Navigation

Use TanStack Router's navigation hooks for programmatic navigation:
```tsx
import { useRouter } from '@tanstack/react-router';

const router = useRouter();
router.navigate({ to: '/dashboard' });
```

Or use the Link component for declarative navigation:
```tsx
import { Link } from '@tanstack/react-router';

<Link to="/profile">View Profile</Link>
```
