### 1. **Request ID Tracking (Distributed Tracing)**

**Status:** ✅ Implemented  
**Priority:** HIGH  
**File:** `shared-lib/src/middleware/request_id.rs`

**Purpose:**

- Track requests across multiple services
- Debug issues in production
- Correlate logs across services
- Required for Jaeger/OpenTelemetry

#### Phase Differences

| Aspect | Phase 1 (Development) | Phase 2 (Production) |
|--------|----------------------|---------------------|
| **Request ID Source** | Generated by each service | Generated by API Gateway (Traefik) then propagated |
| **Header Name** | `X-Request-ID` | `X-Request-ID` (standard) |
| **ID Format** | UUID v4 | UUID v4 |
| **Propagation** | Manual in service-to-service calls via NATS | Automatic via gateway headers + NATS metadata |
| **Tracing Backend** | Console logs only | Jaeger/OpenTelemetry (future) |
| **Service Access** | Direct localhost:800X | Via gateway (traefik routes) |

**Implementation:**

```rust
// shared-lib/src/middleware/request_id.rs
use actix_web::{
    dev::{forward_ready, Service, ServiceRequest, ServiceResponse, Transform},
    Error, HttpMessage,
};
use futures_util::future::LocalBoxFuture;
use std::future::{ready, Ready};
use uuid::Uuid;

pub struct RequestId(pub String);

pub struct RequestIdMiddleware;

impl<S, B> Transform<S, ServiceRequest> for RequestIdMiddleware
where
    S: Service<ServiceRequest, Response = ServiceResponse<B>, Error = Error>,
    S::Future: 'static,
    B: 'static,
{
    type Response = ServiceResponse<B>;
    type Error = Error;
    type InitError = ();
    type Transform = RequestIdMiddlewareService<S>;
    type Future = Ready<Result<Self::Transform, Self::InitError>>;

    fn new_transform(&self, service: S) -> Self::Future {
        ready(Ok(RequestIdMiddlewareService { service }))
    }
}

pub struct RequestIdMiddlewareService<S> {
    service: S,
}

impl<S, B> Service<ServiceRequest> for RequestIdMiddlewareService<S>
where
    S: Service<ServiceRequest, Response = ServiceResponse<B>, Error = Error>,
    S::Future: 'static,
    B: 'static,
{
    type Response = ServiceResponse<B>;
    type Error = Error;
    type Future = LocalBoxFuture<'static, Result<Self::Response, Self::Error>>;

    forward_ready!(service);

    fn call(&self, req: ServiceRequest) -> Self::Future {
        // Phase 1: Generate if missing
        // Phase 2: Extract from gateway X-Request-ID header
        let request_id = req.headers()
            .get("X-Request-ID")
            .and_then(|h| h.to_str().ok())
            .map(|s| s.to_string())
            .unwrap_or_else(|| Uuid::new_v4().to_string());
        
        // Attach to request extensions
        req.extensions_mut().insert(RequestId(request_id.clone()));
        
        let fut = self.service.call(req);
        
        Box::pin(async move {
            let mut res = fut.await?;
            
            // Add to response headers
            res.headers_mut().insert(
                actix_web::http::header::HeaderName::from_static("x-request-id"),
                actix_web::http::header::HeaderValue::from_str(&request_id)
                    .unwrap_or_else(|_| actix_web::http::header::HeaderValue::from_static("invalid"))
            );
            
            Ok(res)
        })
    }
}
```

**Usage in Services:**

```rust

    App::new()
        .wrap(RequestIdMiddleware)  // First middleware
        .service(my_handler)
})
```

### 2. **Rate Limiting Middleware**

**Status:** ✅ Implemented  
**Priority:** HIGH  
**File:** `shared-lib/src/middleware/rate_limit.rs`

**Purpose:**

- Prevent abuse (brute force, spam)
- Protect invitation system (max 10 invitations/day)
- API quota enforcement
- DDoS mitigation

#### Phase Differences

| Aspect | Phase 1 (Development) | Phase 2 (Production) |
|--------|----------------------|---------------------|
| **Rate Limit Enforcement** | Per-service Redis (local) | Shared Redis cluster (global) |
| **Limit Scope** | Per-IP address | Per-IP + Per-User + Per-Territory |
| **Bypass Mechanism** | Dev mode disabled | None (enforced) |
| **Limit Configuration** | Hardcoded in code | Environment variables |
| **Headers** | Optional | Required (X-RateLimit-*) |
| **Gateway Integration** | None | Traefik rate limiting + service-level |

**Implementation:**

```rust
// shared-lib/src/middleware/rate_limit.rs
use actix_web::{dev::ServiceRequest, Error, HttpResponse};
use redis::AsyncCommands;
use std::time::Duration;

pub struct RateLimitConfig {
    pub enabled: bool,
    pub login: u32,           // 5 requests/min
    pub register: u32,        // 3 requests/min
    pub profile_read: u32,    // 100 requests/min
    pub profile_write: u32,   // 10 requests/min
    pub invitation: u32,      // 10 requests/day
}

impl Default for RateLimitConfig {
    fn default() -> Self {
        Self {
            enabled: std::env::var("RATE_LIMIT_ENABLED")
                .unwrap_or_else(|_| "false".to_string())
                .parse()
                .unwrap_or(false),
            login: 5,
            register: 3,
            profile_read: 100,
            profile_write: 10,
            invitation: 10,
        }
    }
}

pub async fn check_rate_limit(
    redis: &mut redis::aio::Connection,
    key: &str,
    limit: u32,
    window_secs: u64,
) -> Result<bool, Error> {
    let count: u32 = redis.incr(key, 1).await
        .map_err(|e| actix_web::error::ErrorInternalServerError(e))?;
    
    if count == 1 {
        redis.expire(key, window_secs as usize).await
            .map_err(|e| actix_web::error::ErrorInternalServerError(e))?;
    }
    
    Ok(count <= limit)
}
```

**Usage:**

```rust
// In handler
let ip = req.peer_addr()
    .map(|addr| addr.ip().to_string())
    .unwrap_or_else(|| "unknown".to_string());

let key = format!("rate_limit:login:{}", ip);

if !check_rate_limit(&mut redis, &key, 5, 60).await? {
    return Err(ErrorTooManyRequests("Rate limit exceeded"));
}
```

**Response Headers:**

### 3. **CORS Middleware Configuration**

**Status:** ✅ Implemented  
**Priority:** HIGH  
**File:** `shared-lib/src/middleware/cors.rs`

**Purpose:**

- Frontend needs to call backend APIs
- Multi-pod deployment (cross-domain requests)
- Security (prevent unauthorized domains)

#### Phase Differences

| Aspect | Phase 1 (Development) | Phase 2 (Production) |
|--------|----------------------|---------------------|
| **Allowed Origins** | `http://localhost:5173` (Vite dev server) | Specific domains: `https://unityplatform.org`, `https://dk.unityplatform.org`, etc. |
| **Credentials** | Enabled (cookies, auth headers) | Enabled (cookies, auth headers) |
| **Configuration** | Permissive (all origins in dev) | Strict whitelist only |
| **Preflight Caching** | Optional (0 seconds) | Required (3600 seconds) |
| **Exposed Headers** | Optional | Required (X-Request-ID, X-RateLimit-*) |

**Implementation:**

```rust
// shared-lib/src/middleware/cors.rs
use actix_cors::Cors;
use actix_web::http::header;

pub fn cors_config_dev() -> Cors {
    Cors::permissive()  // Allow all origins for local development
}

pub fn cors_config_prod() -> Cors {
    Cors::default()
        .allowed_origin("https://unityplatform.org")
        .allowed_origin("https://dk.unityplatform.org")
        .allowed_origin("https://no.unityplatform.org")
        .allowed_origin("https://se.unityplatform.org")
        .allowed_origin("https://eu.unityplatform.org")
        .allowed_methods(vec!["GET", "POST", "PUT", "DELETE", "PATCH", "OPTIONS"])
        .allowed_headers(vec![
            header::AUTHORIZATION,
            header::ACCEPT,
            header::CONTENT_TYPE,
        ])
        .expose_headers(vec![
            "X-Request-ID",
            "X-RateLimit-Limit",
            "X-RateLimit-Remaining",
            "X-RateLimit-Reset",
        ])
        .max_age(3600)
        .supports_credentials()
}

pub fn cors_config() -> Cors {
    let env = std::env::var("ENVIRONMENT").unwrap_or_else(|_| "development".to_string());
    
    match env.as_str() {
        "production" => cors_config_prod(),
        _ => cors_config_dev(),
    }
}
```

**Usage:**

```rust
use shared_lib::middleware::cors_config;

HttpServer::new(|| {
    App::new()
        .wrap(cors_config())  // Apply CORS
        .service(my_handler)
})
```

### 4. **Error Handling & Response Formatting**

**Status:** ✅ Implemented  
**Priority:** HIGH  
**File:** `shared-lib/src/middleware/error_handler.rs`

**Purpose:**

- Consistent error responses across services
- Better debugging
- Frontend error handling
- User-friendly messages

#### Phase Differences

| Aspect | Phase 1 (Development) | Phase 2 (Production) |
|--------|----------------------|---------------------|
| **Error Details** | Full stack traces exposed | Stack traces hidden from clients |
| **Logging Level** | Debug logs enabled | Info/warn/error only |
| **Error Reporting** | Console only | Sentry/error tracking service |
| **Request ID** | Optional in errors | Always included in errors |
| **Internal Errors** | Show database/service errors | Generic "Internal Server Error" |

**Implementation:**

```rust
// shared-lib/src/middleware/error_handler.rs
use actix_web::{error, http::StatusCode, HttpRequest, HttpResponse};
use serde::Serialize;
use chrono::Utc;

#[derive(Serialize)]
pub struct ErrorResponse {
    pub error: String,
    pub message: String,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub request_id: Option<String>,
    pub timestamp: i64,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub details: Option<serde_json::Value>,
}

pub fn error_handler(
    err: actix_web::Error,
    req: &HttpRequest,
) -> actix_web::Error {
    let request_id = req.extensions()
        .get::<crate::middleware::RequestId>()
        .map(|r| r.0.clone());
    
    let is_dev = std::env::var("ENVIRONMENT")
        .unwrap_or_else(|_| "development".to_string()) == "development";
    
    let error_response = if is_dev {
        // Phase 1: Show detailed errors
        ErrorResponse {
            error: "internal_server_error".to_string(),
            message: err.to_string(),
            request_id,
            timestamp: Utc::now().timestamp(),
            details: Some(serde_json::json!({
                "debug": format!("{:?}", err)
            })),
        }
    } else {
        // Phase 2: Hide internals
        ErrorResponse {
            error: "internal_server_error".to_string(),
            message: "An unexpected error occurred".to_string(),
            request_id,
            timestamp: Utc::now().timestamp(),
            details: None,
        }
    };
    
    error::InternalError::from_response(
        err,
        HttpResponse::InternalServerError().json(error_response)
    ).into()
}
```

#### LoggingMiddleware with Metrics

```rust
// shared-lib/src/middleware/logging.rs
use crate::metrics::MetricsCollector;

#[derive(Debug, Clone)]
pub struct LoggingMiddleware {
    verbose: bool,
    metrics: Option<MetricsCollector>,
}

impl LoggingMiddleware {
    /// Development logging - verbose with detailed request information
    pub fn development() -> Self {
        Self { verbose: true, metrics: None }
    }

    /// Development logging with automatic metrics collection
    pub fn development_with_metrics(metrics: MetricsCollector) -> Self {
        Self { verbose: true, metrics: Some(metrics) }
    }

    /// Production logging - minimal, only essential information
    pub fn production() -> Self {
        Self { verbose: false, metrics: None }
    }

    /// Production logging with automatic metrics collection
    pub fn production_with_metrics(metrics: MetricsCollector) -> Self {
        Self { verbose: false, metrics: Some(metrics) }
    }
}

impl<S, B> Service<ServiceRequest> for LoggingMiddlewareService<S>
where
    S: Service<ServiceRequest, Response = ServiceResponse<B>, Error = Error>,
    S::Future: 'static,
    B: 'static,
{
    fn call(&self, req: ServiceRequest) -> Self::Future {
        let start = Instant::now();
        let method = req.method().to_string();
        let path = req.path().to_string();
        let metrics = self.metrics.clone();
        
        let fut = self.service.call(req);
        
        Box::pin(async move {
            let res = fut.await?;
            let status = res.status();
            let duration = start.elapsed();

            // Automatically record metrics if collector is available
            if let Some(ref collector) = metrics {
                collector.record_request(
                    &method,
                    &path,
                    status.as_u16(),
                    duration.as_secs_f64()
                );
            }

            // Log based on status code
            if status.is_server_error() {
                tracing::error!(/* ... */);
            } else if status.is_client_error() {
                tracing::warn!(/* ... */);
            } else {
                tracing::info!(/* ... */);
            }
            
            Ok(res)
        })
    }
}
```

```rust
async fn metrics_endpoint(
    db: web::Data<Database>,
    collector: web::Data<MetricsCollector>,

        Some(pool_idle)
```

|--------|----------------------|---------------------|

```rust
// shared-lib/src/middleware/security_headers.rs
use actix_web::{
    dev::{forward_ready, Service, ServiceRequest, ServiceResponse, Transform},
    Error,
    http::header::{HeaderName, HeaderValue},
};
use futures_util::future::LocalBoxFuture;
use std::future::{ready, Ready};

pub struct SecurityHeadersMiddleware {
    production: bool,
}

impl SecurityHeadersMiddleware {
    pub fn new() -> Self {
        let production = std::env::var("ENVIRONMENT")
            .unwrap_or_else(|_| "development".to_string()) == "production";
        Self { production }
    }
}

impl<S, B> Transform<S, ServiceRequest> for SecurityHeadersMiddleware
where
    S: Service<ServiceRequest, Response = ServiceResponse<B>, Error = Error>,
    S::Future: 'static,
    B: 'static,
{
    type Response = ServiceResponse<B>;
    type Error = Error;
    type InitError = ();
    type Transform = SecurityHeadersMiddlewareService<S>;
    type Future = Ready<Result<Self::Transform, Self::InitError>>;

    fn new_transform(&self, service: S) -> Self::Future {
        ready(Ok(SecurityHeadersMiddlewareService {
            service,
            production: self.production,
        }))
    }
}

pub struct SecurityHeadersMiddlewareService<S> {
    service: S,
    production: bool,
}

impl<S, B> Service<ServiceRequest> for SecurityHeadersMiddlewareService<S>
where
    S: Service<ServiceRequest, Response = ServiceResponse<B>, Error = Error>,
    S::Future: 'static,
    B: 'static,
{
    type Response = ServiceResponse<B>;
    type Error = Error;
    type Future = LocalBoxFuture<'static, Result<Self::Response, Self::Error>>;

    forward_ready!(service);

    fn call(&self, req: ServiceRequest) -> Self::Future {
        let production = self.production;
        let fut = self.service.call(req);
        
        Box::pin(async move {
            let mut res = fut.await?;
            
            let headers = res.headers_mut();
            
            // Always apply these headers
            headers.insert(
                HeaderName::from_static("x-content-type-options"),
                HeaderValue::from_static("nosniff")
            );
            
            headers.insert(
                HeaderName::from_static("x-xss-protection"),
                HeaderValue::from_static("1; mode=block")
            );
            
            headers.insert(
                HeaderName::from_static("referrer-policy"),
                HeaderValue::from_static("strict-origin-when-cross-origin")
            );
            
            if production {
                // Phase 2: Strict production headers
                headers.insert(
                    HeaderName::from_static("x-frame-options"),
                    HeaderValue::from_static("DENY")
                );
                
                headers.insert(
                    HeaderName::from_static("strict-transport-security"),
                    HeaderValue::from_static("max-age=31536000; includeSubDomains")
                );
                
                headers.insert(
                    HeaderName::from_static("content-security-policy"),
                    HeaderValue::from_static("default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'")
                );
            } else {
                // Phase 1: Permissive development headers
                headers.insert(
                    HeaderName::from_static("x-frame-options"),
                    HeaderValue::from_static("SAMEORIGIN")
                );
                
                // No HSTS in development (allow HTTP)
                // Permissive CSP for development
                headers.insert(
                    HeaderName::from_static("content-security-policy"),
                    HeaderValue::from_static("default-src 'self' 'unsafe-inline' 'unsafe-eval'")
                );
            }
            
            Ok(res)
        })
    }
}
```

### 8. **Health Check Endpoints**

**Status:** 📋 Service-Level Pattern (each service implements)  
**Priority:** HIGH  
**File:** Implemented in each service's handlers

**Purpose:**

- Kubernetes liveness/readiness probes
- Load balancer health checks
- Monitoring systems
- Graceful degradation

#### Phase Differences

| Aspect | Phase 1 (Development) | Phase 2 (Production) |
|--------|----------------------|---------------------|
| **Health Endpoint** | `/health` (basic) | `/health` + K8s probes |
| **Readiness Checks** | Database only | Database + Redis + NATS + dependent services |
| **Metrics Endpoint** | Optional `/metrics` | Required `/metrics` (Prometheus) |
| **Dependency Checks** | Local only (DB, Redis, NATS) | Local + remote pods (circuit breakers) |
| **Response Time** | Not critical | Must respond <200ms |
| **Failure Handling** | Log and continue | Mark unhealthy, remove from load balancer |

```rust
pub async fn readiness_check(
    pool: web::Data<sqlx::PgPool>,
    redis: web::Data<redis::Client>,
    // nats: web::Data<NatsClient>,  // Add when NATS client is ready
) -> Result<HttpResponse> {

    // Check database
    let db_ok = sqlx::query("SELECT 1")
        .execute(pool.get_ref())
        .await
        .is_ok();
    checks.insert("database".to_string(), db_ok);
    
    // Check Redis
    let redis_ok = redis.get_async_connection().await.is_ok();
    checks.insert("redis".to_string(), redis_ok);
    
    // Phase 2: Add NATS check
    // let nats_ok = nats.is_connected();
    // checks.insert("nats".to_string(), nats_ok);

    let response = ReadinessResponse {
        status: if all_ready { "ready" } else { "not_ready" }.to_string(),
        checks,
        timestamp: Utc::now().timestamp(),
    };
    
    if all_ready {
        Ok(HttpResponse::Ok().json(response))
    } else {
        Ok(HttpResponse::ServiceUnavailable().json(response))
    }
}

    Ok(HttpResponse::Ok()
        .content_type("text/plain; version=0.0.4")
        .body(buffer))
}
```

### 9. **Graceful Shutdown**

**Status:** ✅ Implemented  
**Priority:** HIGH  
**File:** `shared-lib/src/shutdown.rs`

**Purpose:**

- Zero-downtime deployments
- Kubernetes pod termination
- Database connection cleanup
- Complete in-flight requests

#### Phase Differences

| Aspect | Phase 1 (Development) | Phase 2 (Production) |
|--------|----------------------|---------------------|
| **Shutdown Signal** | Ctrl+C (manual) | SIGTERM from Kubernetes |
| **Grace Period** | 10 seconds (dev convenience) | 30 seconds (production safety) |
| **Connection Draining** | Not critical | Critical (finish all requests) |
| **Database Cleanup** | Optional | Required (close connections) |
| **NATS Cleanup** | Optional | Required (unsubscribe all) |
| **Deployment Strategy** | Manual restart | Rolling update (zero downtime) |

**Implementation:**

```rust
// shared-lib/src/shutdown.rs
use tokio::signal;
use tracing::info;

pub async fn shutdown_signal() {
    let ctrl_c = async {
        signal::ctrl_c()
            .await
            .expect("Failed to install Ctrl+C handler");
    };

    #[cfg(unix)]
    let terminate = async {
        signal::unix::signal(signal::unix::SignalKind::terminate())
            .expect("Failed to install SIGTERM handler")
            .recv()
            .await;
    };

    #[cfg(not(unix))]
    let terminate = std::future::pending::<()>();

    tokio::select! {
        _ = ctrl_c => {
            info!("Received Ctrl+C, initiating graceful shutdown");
        },
        _ = terminate => {
            info!("Received SIGTERM, initiating graceful shutdown");
        },
    }
}
```

**Usage in main.rs:**

```rust
#[actix_web::main]
async fn main() -> std::io::Result<()> {
    // Initialize logging
    tracing_subscriber::fmt::init();
    
    // Create server
    let server = HttpServer::new(|| {
        App::new()
            .service(health_check)
            .service(my_handler)
    })
    .bind("0.0.0.0:8002")?
    .run();
    
    let server_handle = server.handle();
    
    // Spawn server task
    let server_task = tokio::spawn(server);
    
    // Wait for shutdown signal
    shutdown_signal().await;
    
    // Graceful shutdown with timeout
    let grace_period = std::env::var("SHUTDOWN_GRACE_PERIOD")
        .unwrap_or_else(|_| "30".to_string())
        .parse::<u64>()
        .unwrap_or(30);
    
    info!("Starting graceful shutdown ({}s grace period)", grace_period);
    server_handle.stop(true).await;
    
    // Wait for server to finish with timeout
    tokio::select! {
        _ = server_task => {
            info!("Server shutdown complete");
        }
        _ = tokio::time::sleep(tokio::time::Duration::from_secs(grace_period)) => {
            tracing::warn!("Shutdown timeout reached, forcing exit");
        }
    }
    
    // Cleanup resources
    info!("Cleaning up resources...");
    // Close database connections, Redis, NATS, etc.
    
    Ok(())
}
```

### 10. **Circuit Breaker (Inter-Service Calls)**

**Status:** ✅ Implemented  
**Priority:** MEDIUM  
**File:** `shared-lib/src/circuit_breaker.rs`

**Purpose:**

- Prevent cascading failures
- Cross-pod API calls (Alice DK → Bob NO)
- Service degradation (continue working if notification-service down)

#### Phase Differences

| Aspect | Phase 1 (Development) | Phase 2 (Production) |
|--------|----------------------|---------------------|
| **Circuit Breaker Scope** | Not needed (single pod, no cross-pod calls) | Required for cross-pod HTTP calls |
| **Failure Threshold** | N/A | 5 consecutive failures |
| **Timeout/Reset** | N/A | 30 seconds before retry |
| **Fallback Strategy** | Return error immediately | Cached data / degraded mode |
| **Service Dependencies** | Local only (same pod) | Remote pods + external services |
| **Monitoring** | Not applicable | Grafana alerts on open circuits |

**Implementation:**

```rust
// shared-lib/src/circuit_breaker.rs
use std::sync::Arc;
use tokio::sync::RwLock;
use std::time::{Duration, Instant};

#[derive(Debug)]
pub enum CircuitState {
    Closed,
    Open,
    HalfOpen,
}

pub struct CircuitBreaker {
    failure_count: Arc<RwLock<u32>>,
    threshold: u32,
    timeout: Duration,
    last_failure: Arc<RwLock<Option<Instant>>>,
    state: Arc<RwLock<CircuitState>>,
}

impl CircuitBreaker {
    pub fn new(threshold: u32, timeout: Duration) -> Self {
        Self {
            failure_count: Arc::new(RwLock::new(0)),
            threshold,
            timeout,
            last_failure: Arc::new(RwLock::new(None)),
            state: Arc::new(RwLock::new(CircuitState::Closed)),
        }
    }
    
    pub async fn call<F, T, E>(&self, f: F) -> Result<T, CircuitBreakerError<E>>
    where
        F: std::future::Future<Output = Result<T, E>>,
    {
        // Check current state
        let state = self.state.read().await;
        match *state {
            CircuitState::Open => {
                drop(state);
                // Check if timeout has elapsed
                let last_fail = self.last_failure.read().await;
                if let Some(last) = *last_fail {
                    if last.elapsed() >= self.timeout {
                        // Try to transition to half-open
                        drop(last_fail);
                        *self.state.write().await = CircuitState::HalfOpen;
                    } else {
                        return Err(CircuitBreakerError::CircuitOpen);
                    }
                }
            }
            _ => {}
        }
        
        // Try to execute
        match f.await {
            Ok(result) => {
                // Success - reset circuit
                *self.failure_count.write().await = 0;
                *self.last_failure.write().await = None;
                *self.state.write().await = CircuitState::Closed;
                Ok(result)
            },
            Err(e) => {
                // Failure - increment counter
                let mut failures = self.failure_count.write().await;
                *failures += 1;
                
                if *failures >= self.threshold {
                    *self.state.write().await = CircuitState::Open;
                    *self.last_failure.write().await = Some(Instant::now());
                }
                
                Err(CircuitBreakerError::RequestFailed(e))
            }
        }
    }
}

#[derive(Debug)]
pub enum CircuitBreakerError<E> {
    CircuitOpen,
    RequestFailed(E),
}
```

**Usage (Phase 2):**

```rust
use lazy_static::lazy_static;

lazy_static! {
    static ref NORWAY_POD_CIRCUIT: CircuitBreaker = CircuitBreaker::new(
        5,                          // 5 failures
        Duration::from_secs(30)     // 30 second timeout
    );
}

async fn check_user_in_norway_pod(user_id: Uuid) -> Result<bool> {
    NORWAY_POD_CIRCUIT.call(async {
        let client = reqwest::Client::new();
        client.get(&format!("https://no.unityplatform.org/api/v1/users/{}/exists", user_id))
            .send()
            .await?
            .json()
            .await
    }).await
    .map_err(|e| match e {
        CircuitBreakerError::CircuitOpen => {
            Error::ServiceUnavailable("Norway pod unavailable")
        }
        CircuitBreakerError::RequestFailed(e) => {
            Error::RemoteError(e.to_string())
        }
    })
}
```

**Status:** 📋 Service-Level Pattern (each service defines own events)  
**Priority:** MEDIUM  
**File:** Services define event types in models/

**Purpose:**

- Event versioning

| Aspect | Phase 1 (Development) | Phase 2 (Production) |

```rust
// shared-lib/src/events/mod.rs
use serde::{Deserialize, Serialize};
use uuid::Uuid;
use chrono::Utc;

// Base event structure - all events must follow this
#[derive(Serialize, Deserialize, Clone, Debug)]
pub struct Event<T> {
    pub event_id: Uuid,
    pub event_type: String,
    pub version: String,
    pub timestamp: i64,
    pub territory_code: String,
    pub payload: T,
}

impl<T> Event<T> {
    pub fn new(event_type: impl Into<String>, territory_code: impl Into<String>, payload: T) -> Self {
        Self {
            event_id: Uuid::new_v4(),
            event_type: event_type.into(),
            version: "1.0".to_string(),
            timestamp: Utc::now().timestamp(),
            territory_code: territory_code.into(),
            payload,
        }
    }
}

// User events
#[derive(Serialize, Deserialize, Clone, Debug)]
pub struct UserCreatedPayload {
    pub user_id: Uuid,
    pub username: String,
    pub email: Option<String>,
    pub territory_code: String,
}

#[derive(Serialize, Deserialize, Clone, Debug)]
pub struct UserDeletedPayload {
    pub user_id: Uuid,
    pub deleted_by: Uuid,
    pub reason: Option<String>,
}

#[derive(Serialize, Deserialize, Clone, Debug)]
pub struct UserUpdatedPayload {
    pub user_id: Uuid,
    pub fields_changed: Vec<String>,
}

// Community events
#[derive(Serialize, Deserialize, Clone, Debug)]
pub struct CommunityCreatedPayload {
    pub community_id: Uuid,
    pub creator_id: Uuid,
    pub name: String,
    pub territory_code: String,
}

#[derive(Serialize, Deserialize, Clone, Debug)]
pub struct UserJoinedCommunityPayload {
    pub community_id: Uuid,
    pub user_id: Uuid,
}

// Type aliases
pub type UserCreatedEvent = Event<UserCreatedPayload>;
pub type UserDeletedEvent = Event<UserDeletedPayload>;
pub type UserUpdatedEvent = Event<UserUpdatedPayload>;
pub type CommunityCreatedEvent = Event<CommunityCreatedPayload>;
pub type UserJoinedCommunityEvent = Event<UserJoinedCommunityPayload>;
```

### 12. **Middleware Execution Order**

**Priority:** HIGH  
**Status:** 📋 Documentation

#### Phase 1 (Development - Localhost)

**Correct Middleware Order:**

```rust
use shared_lib::middleware::*;

HttpServer::new(|| {
    App::new()
        // 1. Request ID (first - generates ID for all logs)
        .wrap(RequestIdMiddleware)
        
        // 2. Logging (logs all requests with request ID)
        .wrap(LoggingMiddleware)
        
        // 3. Security headers (optional in dev, prepare for prod)
        .wrap(SecurityHeadersMiddleware::new())
        
        // 4. CORS (permissive - allow localhost:5173)
        .wrap(cors_config())
        
        // 5. Rate limiting (DISABLED in dev mode for testing)
        // .wrap(RateLimitMiddleware)  // Commented out in Phase 1
        
        // 6. Input validation (payload size limits)
        .app_data(payload_config())
        
        // 7. JWT authentication (validate user tokens)
        .wrap(JwtAuthMiddleware::new())
        
        // 8. Application routes
        .service(health_check)
        .service(readiness_check)
        .service(metrics)
        .service(create_user)
        .service(get_user)
})
.bind("0.0.0.0:8002")?
.run();
```

**Why This Order:**

1. **Request ID first** → All middleware/logs have correlation ID
2. **Logging second** → Captures all requests (including CORS preflight)
3. **Security headers** → Protects all responses (minimal in dev)
4. **CORS** → Handles OPTIONS preflight before auth (frontend needs this)
5. **Rate limit** → Disabled in dev (can enable for load testing)
6. **Input validation** → Check payload size before parsing
7. **JWT auth** → Validates user for protected routes
8. **Routes last** → Actual application logic

#### Phase 2 (Production - Gateway)

**Correct Middleware Order:**

```rust
use shared_lib::middleware::*;

HttpServer::new(|| {
    App::new()
        // 1. Request ID (extract from gateway X-Request-ID header)
        .wrap(RequestIdMiddleware)
        
        // 2. Logging (JSON format for Loki/ELK)
        .wrap(LoggingMiddleware)
        
        // 3. Security headers (REQUIRED - HSTS, CSP, X-Frame-Options)
        .wrap(SecurityHeadersMiddleware::new())
        
        // 4. CORS (strict whitelist - only unityplatform.org domains)
        .wrap(cors_config())
        
        // 5. Rate limiting (ENABLED - prevent abuse)
        .wrap(RateLimitMiddleware::new())
        
        // 6. Input validation (payload size limits)
        .app_data(payload_config())
        
        // 7. JWT authentication (validate user tokens)
        .wrap(JwtAuthMiddleware::new())
        
        // 8. Application routes
        .service(health_check)
        .service(readiness_check)
        .service(metrics)
        .service(create_user)
        .service(get_user)
})
.bind("0.0.0.0:8002")?
.run();
```

**Key Differences:**

| Middleware | Phase 1 | Phase 2 |
|-----------|---------|---------|
| Request ID | Generate if missing | Extract from gateway (X-Request-ID) |
| Logging | Console, human-readable | JSON, sent to Loki |
| Security Headers | Optional/permissive | Required (HSTS, CSP) |
| CORS | Permissive (localhost) | Strict whitelist |
| Rate Limiting | Disabled | Enabled |
| Input Validation | Same | Same |
| JWT Auth | Same | Same |
